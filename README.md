# Hytpotchi

Лаунчер Minecraft для Windows на Tauri 2 + React 19 + Rust.

## Скачать и установить

1. Скачайте `Hytpotchi_x.y.z_x64-setup.exe` со страницы релизов.
2. Запустите установщик. Права администратора не нужны: лаунчер ставится для текущего пользователя.
3. Windows может показать «Система Windows защитила ваш компьютер», потому что установщик пока
   не подписан сертификатом. Нажмите **Подробнее → Выполнить в любом случае**.
4. Откройте Hytpotchi, добавьте аккаунт и создайте сборку. Игра, моды и нужная Java скачаются сами.

Требования: Windows 10/11 x64 и интернет при первом запуске сборки. WebView2 обычно уже есть
в системе, а если нет — установщик скачает его сам.

> **Владельцу проекта:** как выложить лаунчер для всех и подключить сервисы — пошаговая инструкция
> для новичков в [docs/SETUP.md](docs/SETUP.md).

## Возможности

- **Сборки**: Vanilla, Fabric, Forge, NeoForge, Quilt — любая версия от 1.0 до последних снапшотов.
- **Java ставится сама**: лаунчер читает из манифеста версии, какая Java ей нужна
  (8 / 17 / 21 / 25 …), и скачивает Eclipse Temurin с проверкой SHA-256.
- **Моды и модпаки с Modrinth**: стабильные версии под сборку, зависимости, обновления,
  импорт/экспорт `.mrpack`, импорт из Prism, MultiMC, CurseForge и `.minecraft`.
- **Аккаунты**: Hytpotchi (уникальный ник + пароль, код восстановления) и Microsoft (device code). Токены шифруются AES-256-GCM, ключ защищён DPAPI.
- **Скины**: библиотека скинов, плащи Microsoft, скины аккаунтов Hytpotchi через CustomSkinLoader и сервер Hytpotchi.
- **Друзья**: друзья по нику, кто в сети и во что играет, приглашения, «Присоединиться» к миру друга без модов (туннель через сервер Hytpotchi).
- Миры с резервными копиями, скриншоты, серверы с пингом и быстрым входом, анализатор крашей.

## Разработка

```bash
npm install
npm run tauri dev
```

Установщик (`src-tauri/target/release/bundle/nsis/`):

```bash
npm run tauri build
```

Только интерфейс в браузере (демо-данные, без бэкенда):

```bash
npm run dev
```

### Что вшивается при сборке

Переменные окружения на момент `npm run tauri build`:

| Переменная | Для чего |
|---|---|
| `HYTPOTCHI_MS_CLIENT_ID` | Вход через Microsoft (Azure App, «Personal Microsoft accounts», public client flows + одобрение Mojang) |
| `HYTPOTCHI_SKIN_SERVER` | Адрес сервера общих скинов (см. `server/skins`) |
| `HYTPOTCHI_DISCORD_ID` | Application ID для статуса в Discord |

Без них лаунчер работает, но соответствующие функции отключены (без сервера Hytpotchi — аккаунты Hytpotchi и друзья): сборки,
моды и скины в библиотеке доступны всегда.

## Где лежат данные

`%APPDATA%\.hytpotchi` (переопределяется `HYTPOTCHI_HOME`):

```
versions/   libraries/   assets/   java/temurin-<N>/   instances/<id>/minecraft/
```
