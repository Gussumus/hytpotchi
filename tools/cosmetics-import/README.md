# Импорт 3D-моделей в косметику

Переводит модели `.glb`/`.gltf` (например, со Sketchfab) в меш-косметику Hytpotchi: упрощает
сетку, ужимает текстуры, сажает модель на кость персонажа и кладёт файлы туда, откуда их раздаёт
сервер (`server/skins/assets/cosmetics/<id>/`). Меш-детали попадают в каталог через
`server/skins/src/cosmetics-meshes.ts`.

```bash
cd tools/cosmetics-import
npm install
node import.mjs              # все предметы из items/
node import.mjs crown        # только корона
node import.mjs crown --nodes  # плюс список узлов сцены (для фильтра nodes)
```

Скачанные модели — в `models/<id>/` (архив Sketchfab распаковать как есть, файл найдётся сам).
В git они не попадают: у каждой своя лицензия. Берите только CC0 и CC BY — и указывайте автора
в `credit`, лаунчер его показывает.

## Конфиг `items/<id>.json`

| Поле | Что это |
|---|---|
| `id` | Предмет каталога. Если такой уже есть (из кубов), модель рисуется вместо кубов, а кубы остаются старым клиентам |
| `name`, `slot` | Только для нового предмета или чтобы переименовать |
| `source` | Папка или файл модели |
| `credit` | `title`, `author`, `url`, `license` |
| `bone` | `head` · `body` · `left_arm` · `right_arm` |
| `rotate` | Поворот модели в градусах `[x, y, z]` до посадки — если она смотрит не туда |
| `fit` | Размер: `{axis: "x"\|"y"\|"z"\|"max", size}` — габарит по оси в пикселях; `{axis: "scale", size: 16}` — просто множитель (модели из Blockbench уже в пикселях: 1 единица = 16) |
| `anchor` | Какая точка габарита садится на кость, доли `[x, y, z]`: `[0.5, 1, 0.5]` — низ по центру, `[0.5, 0.5, 0]` — середина передней грани |
| `at` | Куда она садится, пиксели модели Minecraft (Y вниз, лицо в −Z). Макушка головы — `[0, -8, 0]`, спина — `z = 2` |
| `rot`, `anim` | Поворот детали (радианы) и анимация: `flap_left` · `flap_right` · `sway` · `spin` |
| `split` | `"x"` — разрезать на левую и правую половины (крылья машут) |
| `nodes` | `{include, exclude}` — регулярные выражения по пути узлов: взять из модели только предмет |
| `maxTriangles`, `textureSize` | Пределы: по умолчанию 2500 треугольников и 256 px |
