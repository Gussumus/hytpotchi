## Словарик: что все эти слова значат

**Репозиторий (репо)** — папка с вашим проектом, но на сайте GitHub. Там хранится код и оттуда люди скачивают лаунчер.

**GitHub** — сайт, где хранят код. Мы используем его как «склад» для установщика и как «завод», который сам собирает лаунчер.

**Коммит** — сохранённая точка в истории проекта (как «сохранение» в игре). Я уже сделал несколько коммитов.

**Push (запушить)** — отправить ваши коммиты с компьютера на GitHub.

**Тег (tag)** — метка версии, например `v0.2.0`. Когда вы отправляете тег на GitHub, он сам собирает новую версию лаунчера.

**Релиз (Release)** — страница на GitHub с готовым установщиком для скачивания.

**GitHub Actions** — «робот» на GitHub, который по команде собирает лаунчер. Ваш компьютер для этого не нужен.

**Секрет (Secret)** — скрытое значение в настройках GitHub (например, ключ). Его никто не видит, даже вы после сохранения.

**Переменная (Variable)** — обычное, не секретное значение в настройках GitHub (например, адрес сервера).

**Ключ подписи** — файл, которым «расписываются» обновления. Лаунчер у игроков примет обновление, только если на нём ваша подпись. Так никто не сможет подсунуть вирус под видом обновления.

**Терминал** — окно, куда вводят команды текстом. Как его открыть — ниже.

## Как открыть терминал в папке проекта

Многие шаги начинаются со слов «выполните команду». Делается это так:

1. Откройте **Проводник** и зайдите в папку проекта:
   `Рабочий стол → Hytpotchi`
2. Нажмите **правой кнопкой мыши по пустому месту** внутри папки.
3. Выберите **«Открыть в Терминале»**.
   (Если такого пункта нет: нажмите «Показать дополнительные параметры» → «Открыть в Терминале»,
   или зажмите **Shift** и нажмите правой кнопкой → «Открыть окно PowerShell здесь».)
4. Откроется окно с мигающим курсором. Проверьте, что в начале строки написано что-то вроде
   `PS C:\Users\akiom31\OneDrive\Рабочий стол\Hytpotchi>` — значит, вы в нужной папке.

Чтобы выполнить команду: **скопируйте** её из инструкции, **вставьте** в терминал
(правая кнопка мыши или **Ctrl+V**) и нажмите **Enter**.

> ⚠️ Вставляйте команды по одной и дожидайтесь, пока она закончит работу
> (снова появится строка `PS C:\...>`).
