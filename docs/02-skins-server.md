# Шаг 2. Сервер скинов: офлайн-скины видны всем

**Что получите в конце:** игрок с офлайн-аккаунтом надевает скин в лаунчере — и все,
кто играет через Hytpotchi, видят этот скин в игре (в сборках с Fabric, Forge, NeoForge или Quilt).

**Время:** ~15 минут. **Стоимость:** бесплатно (лимита Cloudflare хватает на тысячи игроков).

**Нужно заранее:** сделанный [Шаг 1](01-github.md) (для последнего пункта).

[← К оглавлению](SETUP.md)

---

## Как это устроено (коротко)

Скины хранятся на маленьком сервере в Cloudflare. Код сервера уже написан и лежит в папке
`server/skins`. Вам нужно только «загрузить» его в свой аккаунт Cloudflare — это называется **развернуть (deploy)**.

---

## 2.1. Зарегистрируйтесь в Cloudflare

1. Откройте https://dash.cloudflare.com/sign-up
2. Введите почту и пароль, подтвердите почту.
3. Банковская карта **не нужна**, домен покупать **не нужно**.

---

## 2.2. Войдите в Cloudflare из терминала

1. Откройте терминал в папке проекта (см. [оглавление](SETUP.md#как-открыть-терминал-в-папке-проекта)).
2. Перейдите в папку сервера:

```bash
cd server\skins
```

3. Войдите:

```bash
npx wrangler login
```

4. Если спросит `Need to install the following packages: wrangler... Ok to proceed? (y)` — нажмите **y** и **Enter**.
5. Откроется браузер со страницей Cloudflare → нажмите **Allow**.
6. В терминале появится `Successfully logged in`.

---

## 2.3. Создайте хранилище для скинов

1. Выполните:

```bash
npx wrangler kv namespace create SKINS
```

2. В ответ терминал напишет примерно такое:

```
[[kv_namespaces]]
binding = "SKINS"
id = "3f9a1c0e8b7d4e2a9c6b5d4e3f2a1b0c"
```

3. **Скопируйте длинный набор букв и цифр после `id =`** (без кавычек).

4. Откройте файл настроек сервера в Блокноте:

```bash
notepad wrangler.toml
```

5. Найдите строку:

```
id = "ВСТАВЬТЕ_ID_ИЗ_KV_NAMESPACE_CREATE"
```

   и замените текст в кавычках на скопированный id. Должно получиться так (с вашим id):

```
id = "3f9a1c0e8b7d4e2a9c6b5d4e3f2a1b0c"
```

6. Сохраните (**Ctrl+S**) и закройте Блокнот.

---

## 2.4. Запустите сервер

1. Выполните:

```bash
npx wrangler deploy
```

2. Если Cloudflare попросит придумать **поддомен workers.dev** (`You need to register a workers.dev subdomain`) —
   введите любое короткое слово латиницей, например ваш ник, и нажмите **Enter**.
   (Или откройте https://dash.cloudflare.com → **Workers & Pages** → там появится предложение выбрать поддомен.)
3. В конце будет строка с адресом, например:

```
https://hytpotchi-skins.vash-nik.workers.dev
```

4. **Скопируйте этот адрес** — это адрес вашего сервера скинов.

**Проверка:** откройте этот адрес в браузере. Должно показаться:

```
{"service":"hytpotchi-skins","ok":true}
```

Если показалось — сервер работает ✅.

5. Вернитесь в папку проекта и сохраните изменения (чтобы id хранилища не потерялся):

```bash
cd ..\..
```

```bash
git add server/skins/wrangler.toml
```

```bash
git commit -m "Сервер скинов: id хранилища"
```

```bash
git push
```

---

## 2.5. Подключите сервер к лаунчеру

**Для себя прямо сейчас** (без новой версии):

1. В лаунчере: **Настройки → Общие скины**.
2. Вставьте адрес сервера в поле и нажмите **Проверить и сохранить**.
3. Должно появиться «Сервер скинов подключён».

**Для всех игроков** (чтобы адрес был в лаунчере с самого начала):

1. На GitHub: ваш репозиторий → **Settings → Secrets and variables → Actions**.
2. Вкладка **Variables** (не Secrets!) → **New repository variable**.
3. **Name:** `HYTPOTCHI_SKIN_SERVER`
4. **Value:** адрес сервера, например `https://hytpotchi-skins.vash-nik.workers.dev`
5. **Add variable**.
6. Выпустите новую версию — см. [05-new-version.md](05-new-version.md). После обновления сервер будет у всех.

---

## 2.6. Проверьте

1. Возьмите **офлайн-аккаунт** в лаунчере.
2. **Скины → Добавить скин** → выберите PNG 64×64 → **Надеть**.
3. Должно появиться: «Скин опубликован — его видят другие игроки Hytpotchi».
4. Запустите сборку **с Fabric/Forge/NeoForge/Quilt** (в ванильной не работает).
   Лаунчер сам поставит мод CustomSkinLoader — в консоли сборки будет об этом строчка.
