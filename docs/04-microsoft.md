# Шаг 4. Вход через Microsoft (лицензионный Minecraft)

**Что получите в конце:** игроки с купленным Minecraft входят своим аккаунтом Microsoft,
играют на лицензионных серверах (Hypixel и т.п.), меняют скины и плащи.

**Время:** ~15 минут работы + **ожидание одобрения от Mojang** (обычно от нескольких дней до пары недель).
**Стоимость:** бесплатно.

**Нужно заранее:** аккаунт Microsoft и сделанный [Шаг 1](01-github.md).

[← К оглавлению](SETUP.md)

---

## Почему так сложно

Microsoft пускает к аккаунтам Minecraft только зарегистрированные программы, а Mojang дополнительно
проверяет каждую новую программу вручную. Поэтому шагов два: **зарегистрировать** лаунчер у Microsoft
и **попросить разрешения** у Mojang. Пока разрешения нет, в лаунчере кнопка входа через Microsoft
показывает «Скоро», а офлайн-аккаунты работают как обычно.

---

## 4.1. Зарегистрируйте лаунчер в Microsoft (Azure)

1. Откройте https://portal.azure.com и войдите аккаунтом Microsoft.
   - Если просит «создать бесплатную учётную запись Azure» / ввести карту — сначала попробуйте
     сразу открыть https://entra.microsoft.com (это тот же раздел, часто без карты).
2. В поиске вверху наберите **App registrations** и откройте этот раздел.
   (В Entra: слева **Applications → App registrations**.)
3. Нажмите **+ New registration**.
4. Заполните:
   - **Name:** `Hytpotchi`
   - **Supported account types:** выберите **«Personal Microsoft accounts only»**
     (только личные аккаунты Microsoft — именно на них покупают Minecraft).
   - **Redirect URI** — оставьте пустым.
5. Нажмите **Register**.

---

## 4.2. Включите вход «по коду с другого устройства»

Лаунчер использует вход по коду (показывает код → вы вводите его на сайте Microsoft). Это нужно разрешить:

1. В вашем приложении слева: **Authentication** (или **Manage → Authentication**).
2. Прокрутите вниз до **Advanced settings**.
3. **Allow public client flows** → переключите в **Yes**.
4. Нажмите **Save** вверху или внизу.

---

## 4.3. Скопируйте Client ID

1. Слева: **Overview**.
2. Найдите **Application (client) ID** — строка вида `a1b2c3d4-1234-5678-9abc-def012345678`.
3. Нажмите на значок копирования рядом.

**Сохраните его в заметки** — он понадобится дважды.

---

## 4.4. Попросите разрешение у Mojang

1. Откройте форму: https://aka.ms/mce-reviewappid
2. Заполните (по-английски):
   - **Application ID / Client ID** — вставьте ID из шага 4.3.
   - **Application name** — `Hytpotchi`.
   - **Description / what the app does** — например:
     `Open-source Minecraft: Java Edition launcher (Tauri). Uses Microsoft device code flow to sign in and launch the game.`
   - Ссылка на проект — `https://github.com/ваш-логин/hytpotchi`.
   - Почта для связи.
3. Отправьте форму и **ждите письма**. Обычно это от нескольких дней до пары недель.

> Пока разрешения нет, вход через Microsoft будет заканчиваться ошибкой
> «Minecraft отклонил вход: Client ID ещё не одобрен». Это нормально.

---

## 4.5. После одобрения — вставьте ID в GitHub

1. На GitHub: ваш репозиторий → **Settings → Secrets and variables → Actions**.
2. Вкладка **Variables** → **New repository variable**.
3. **Name:** `HYTPOTCHI_MS_CLIENT_ID`
4. **Value:** Client ID из шага 4.3.
5. **Add variable**.
6. Выпустите новую версию — [05-new-version.md](05-new-version.md).

---

## 4.6. Проверьте

1. Обновите лаунчер.
2. **Аккаунты** → **Войти через Microsoft**.
3. Лаунчер покажет **код** → нажмите **«Скопировать и открыть»** → на сайте Microsoft вставьте код → войдите.
4. Вернитесь в лаунчер — аккаунт появится сам.

---

✅ **Готово!** Теперь работает всё. Как выпускать обновления дальше — [05-new-version.md](05-new-version.md).
