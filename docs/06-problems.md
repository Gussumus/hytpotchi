разберёмся.

## Терминал

### «git не является внутренней или внешней командой»

Git не установлен. Скачайте с https://git-scm.com/download/win, установите (все настройки по умолчанию),
**закройте и откройте терминал заново**.

### «npx не является внутренней или внешней командой»

Не установлен Node.js. Скачайте **LTS** с https://nodejs.org, установите, перезапустите терминал.

### Команда «зависла»

Подождите — некоторые команды (`git push`, `npx wrangler deploy`) работают до минуты.
Если ничего не происходит 5 минут — нажмите **Ctrl+C** и повторите.

## GitHub

### При `git push` просит логин и пароль

GitHub больше не принимает пароль от аккаунта в терминале. Должно открыться окно
**«Connect to GitHub» → Sign in with your browser**. Если окно не появилось — обновите Git
(https://git-scm.com/download/win), в нём есть «Git Credential Manager», который открывает это окно.

### `remote origin already exists`

Адрес уже добавлен. Если адрес неправильный — замените:

```bash
git remote set-url origin https://github.com/ваш-логин/hytpotchi.git
```

### `GH007: Your push would publish a private email address`

Вы включили защиту почты (шаг 1.2), а коммиты ещё со старой почтой. Напишите мне свой noreply-адрес —
я перепишу коммиты.

### `Updates were rejected because the remote contains work that you do not have`

При создании репозитория отметили «Add a README» или лицензию. Проще всего:
удалите репозиторий на GitHub (**Settings** → в самом низу **Delete this repository**) и создайте заново
**без галочек** (шаг 1.3).

### Сборка на GitHub упала (красный крестик ❌)

1. GitHub → **Actions** → нажмите на упавшую задачу → слева **release** (или **check**).
2. Найдите шаг с красным крестиком, раскройте его — внизу будет текст ошибки.
3. Частые причины:
   - **«Не задан секрет TAURI_SIGNING_PRIVATE_KEY»** — пропущен [шаг 1.5](01-github.md#15-добавьте-ключ-подписи-обновлений)
     или имя секрета написано с ошибкой.
   - **«failed to decode secret key» / ошибки подписи** — ключ вставлен не полностью. Удалите секрет и вставьте заново
     через **Ctrl+A → Ctrl+C** в Блокноте.
   - **Тесты не прошли** — скопируйте ошибку и отправьте мне.
4. После исправления выпустите следующую версию (см. [05-new-version.md](05-new-version.md)).

### Лаунчер не предлагает обновиться

- Установлена версия **с GitHub** (а не собранная на компьютере)? Только они умеют обновляться.
  Проверка: **Настройки → О программе** → зелёная точка у «Обновления».
- Новая версия больше старой? `v0.2.0` → `v0.2.1` — да, `v0.2.1` → `v0.2.0` — нет.
- Сборка на GitHub завершилась с зелёной галочкой и в релизе есть файл **latest.json**?
- Репозиторий **публичный**? У приватного обновления скачать нельзя.

## Cloudflare (сервер скинов)

### `You need to register a workers.dev subdomain`

Откройте https://dash.cloudflare.com → **Workers & Pages** → выберите поддомен → затем снова `npx wrangler deploy`.

### `KV namespace ... is not valid` / ошибка про id

В `server\skins\wrangler.toml` неправильно вставлен id (шаг 2.3). Проверьте, что он в кавычках и без пробелов.

### В лаунчере «По этому адресу не сервер скинов Hytpotchi»

Откройте адрес в браузере — должно показаться `{"service":"hytpotchi-skins","ok":true}`.
Если нет — сервер не развёрнут, повторите `npx wrangler deploy`. Адрес должен начинаться с `https://`.

### «Этот ник уже занят другим игроком Hytpotchi»

Кто-то уже загрузил скин на этот ник. Выберите другой ник для офлайн-аккаунта.

## Установщик

### «Система Windows защитила ваш компьютер»

Это нормально для программ без платной цифровой подписи. Нажмите **Подробнее → Выполнить в любом случае**.
Чтобы убрать предупреждение совсем, нужен сертификат подписи кода (платный) или бесплатный для open-source
проектов через https://signpath.org.

### Антивирус ругается на установщик

Новые неподписанные программы иногда ошибочно помечаются антивирусами. Можно отправить файл на проверку
в ваш антивирус как «ложное срабатывание». Со временем, когда установщик скачает больше людей, это проходит.

## Игра

### Игра вылетает

Откройте сборку → вкладка **Консоль**. Если лаунчер понял причину, он показывает подсказку жёлтым над кнопкой
«Играть». Если не понял — скопируйте последние строки консоли и отправьте мне.
