# Как обновить сервер Hytpotchi

Сервер (скины, аккаунты, друзья, косметика, магазин) живёт на Cloudflare и обновляется **отдельно**
от лаунчера. Выпуск новой версии лаунчера ([05-new-version.md](05-new-version.md)) сервер не трогает,
и наоборот.

**Когда нужно:** поменяли что-то в папке `server\skins` — цены, предметы косметики, код сервера.
**Время:** 1–2 минуты. Игроки ничего не замечают: обновление без перерыва.

[← К оглавлению](SETUP.md)

## Обновление по шагам

Откройте терминал в папке проекта ([как](SETUP.md#как-открыть-терминал-в-папке-проекта)).

**1. Перейдите в папку сервера:**

```bash
cd server\skins
```

**2. Проверьте, что ничего не сломали** — запустите тесты (каждая строка — отдельная команда):

```bash
node --experimental-strip-types test/cosmetics.test.mjs
```

```bash
node --experimental-strip-types test/shop.test.mjs
```

```bash
node --experimental-strip-types test/worker.test.mjs
```

Каждая должна закончиться словами **«все проверки пройдены»** (или `all checks passed`).
Если вылезло красное `AssertionError` — **не выкладывайте**, сначала исправьте (или скиньте ошибку Claude).

**3. Выложите:**

```bash
npx wrangler deploy
```

В конце должно быть `Deployed hytpotchi-skins` и адрес `https://hytpotchi-skins.akiom31.workers.dev`.

> Если пишет, что вы не вошли в Cloudflare, — сначала `npx wrangler login`
> (откроется браузер, нажмите «Allow»).

**4. Сохраните изменения на GitHub** (чтобы не потерять):

```bash
cd ..\..
```

```bash
git add -A
```

```bash
git commit -m "Сервер: коротко, что изменилось"
```

```bash
git push
```

## Откатить неудачное обновление

Если после `deploy` что-то сломалось — верните предыдущую версию сервера одной командой
(из папки `server\skins`):

```bash
npx wrangler rollback
```

Спросит подтверждение — нажмите **y** и **Enter**. Данные игроков (аккаунты, скины, покупки) при этом
**не теряются**: откатывается только код.

## Посмотреть, что происходит на сервере

Ошибки и запросы в реальном времени (из папки `server\skins`):

```bash
npx wrangler tail
```

Оставьте окно открытым и повторите то, что не работает, — увидите ошибку. Выйти — **Ctrl+C**.

## Секреты сервера

Секреты — скрытые настройки сервера (ключи, пароли). Кладутся командой
`npx wrangler secret put ИМЯ` из папки `server\skins`: команда спросит значение — вставьте и нажмите Enter.
Новый секрет начинает работать сразу, `deploy` не нужен.

| Секрет | Для чего | Где взять |
|---|---|---|
| `ADMIN_NICKS` | Кто видит вкладку «Админ» в «Косметике». Ники через запятую: `gussumus,другой_ник` | Сами придумываете |
| `YOOKASSA_SHOP_ID` | Номер магазина ЮKassa | [07-payments.md](07-payments.md), шаг 7.3 |
| `YOOKASSA_SECRET_KEY` | Секретный ключ ЮKassa | [07-payments.md](07-payments.md), шаг 7.3 |
| `RELAY_URL`, `RELAY_KEY` | Адрес и ключ релея в России для игры без VPN | Уже положены. Подробности — [server/relay/README.md](../server/relay/README.md) |
| `YGG_PRIVATE_KEY` | Подпись скинов на ванилле | Уже положен, не трогайте |

Посмотреть, какие секреты уже есть (значения не показываются):

```bash
npx wrangler secret list
```

> ⚠️ Секреты задаются **только командой**, не в файле `wrangler.toml`: при `deploy` то, что
> написано в `[vars]` этого файла, перезаписывает настройки.

## Выдать или забрать косметику

**Из лаунчера (проще):** «Косметика» → вкладка **«Админ»** → ник игрока → **«Найти»** →
нажмите на предмет, чтобы выдать или забрать. Есть кнопки «Выдать всё» и «Забрать всё».
Вкладку видят только ники из `ADMIN_NICKS`.

**Скриптом** (из папки проекта, нужен вход в Cloudflare):

```powershell
.\tools\grant-cosmetics.ps1 -Nick ник -All
```

```powershell
.\tools\grant-cosmetics.ps1 -Nick ник crown halo
```

```powershell
.\tools\grant-cosmetics.ps1 -Nick ник crown -Remove
```

## Частые изменения

| Хочу | Где править | Потом |
|---|---|---|
| Поменять цену | `server/skins/src/cosmetics.ts` и `cosmetics-extra.ts`, поле `price` (рубли, `0` — бесплатно) | `deploy` |
| Переименовать предмет | там же, поле `name` | `deploy` |
| Что с чем нельзя надеть вместе | `server/skins/src/cosmetics.ts`, список `SPOTS` (одинаковое место — вместе нельзя) | `deploy` |
| Добавить 3D-предмет | `tools/cosmetics-import` (см. его README) | `deploy` |
| Добавить админа | секрет `ADMIN_NICKS` | ничего |

Лаунчер после этих изменений выпускать **не нужно** — он берёт каталог с сервера.

Застряли — напишите Claude, что видите, и приложите скриншот.
