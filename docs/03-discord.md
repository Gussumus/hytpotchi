# Шаг 3. Статус «Играет в Hytpotchi» в Discord

**Что получите в конце:** когда кто-то играет через Hytpotchi, у него в Discord видно
«Играет в Hytpotchi», название сборки, версию или сервер и сколько времени он играет.

**Время:** ~5 минут. **Стоимость:** бесплатно.

**Нужно заранее:** аккаунт Discord и сделанный [Шаг 1](01-github.md).

[← К оглавлению](SETUP.md)

---

## Зачем это нужно

Discord показывает статус только для «зарегистрированных» программ. Каждая игра регистрирует себя
один раз и получает номер — **Application ID**. Мы зарегистрируем Hytpotchi, а номер вставим в лаунчер.
Игрокам ничего делать не нужно.

---

## 3.1. Создайте приложение в Discord

1. Откройте https://discord.com/developers/applications и войдите своим аккаунтом Discord.
2. Справа вверху нажмите **New Application**.
3. **Name:** `Hytpotchi` — именно это слово будет в статусе «Играет в **Hytpotchi**».
4. Поставьте галочку согласия с правилами → **Create**.

---

## 3.2. Добавьте картинку (необязательно, но красиво)

1. На странице приложения слева: **General Information**.
   - **App Icon** → загрузите файл `src-tauri\icons\icon.png` из папки проекта → **Save Changes** внизу.
2. Слева: **Rich Presence** → **Art Assets**.
3. **Add Image(s)** → выберите тот же `src-tauri\icons\icon.png` (он 512×512 — Discord требует не меньше).
4. Назовите картинку **`logo`** (маленькими буквами, именно так — лаунчер ищет картинку с этим именем).
5. **Save Changes**.

> Картинка в статусе может появиться не сразу — Discord иногда обновляет их до 10–15 минут.

---

## 3.3. Скопируйте Application ID

1. Слева: **General Information**.
2. Найдите поле **Application ID** — длинное число, например `1312345678901234567`.
3. Нажмите **Copy** рядом с ним.

---

## 3.4. Вставьте ID в GitHub

1. На GitHub: ваш репозиторий → **Settings → Secrets and variables → Actions**.
2. Вкладка **Variables** → **New repository variable**.
3. **Name:** `HYTPOTCHI_DISCORD_ID`
4. **Value:** вставьте Application ID.
5. **Add variable**.
6. Выпустите новую версию — [05-new-version.md](05-new-version.md).

---

## 3.5. Проверьте

1. Обновите лаунчер до новой версии.
2. **Настройки** → **Статус в Discord** должен быть включён, а в «О программе» — зелёная точка у «Статус в Discord».
3. Откройте Discord (программу на компьютере, не браузер), запустите любую сборку.
4. В вашем профиле появится «Играет в Hytpotchi».

> Если статуса нет: в Discord → **Настройки пользователя → Конфиденциальность активности** →
> включите **«Делиться информацией о моей активности»**.
