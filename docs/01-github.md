# Шаг 1. GitHub: ссылка на скачивание и автообновление

**Что получите в конце:** страницу, где любой человек скачает установщик Hytpotchi,
и автообновление — когда вы выпустите новую версию, лаунчер у всех обновится сам.

**Время:** ~20 минут. **Стоимость:** бесплатно.

[← К оглавлению](SETUP.md)

---

## 1.1. Зарегистрируйтесь на GitHub

Если аккаунт уже есть — пропустите.

1. Откройте https://github.com/signup
2. Введите почту, придумайте пароль и **имя пользователя (логин)**.
   Логин будет в ссылке на лаунчер, например `github.com/ваш-логин/hytpotchi` — выберите что-то приличное.
3. Подтвердите почту (придёт письмо с кодом).

---

## 1.2. Скройте свою почту (важно!)

Во всех коммитах проекта сейчас записана ваша почта. Когда вы отправите проект на GitHub,
**её сможет увидеть любой**. Чтобы этого не было:

1. На GitHub нажмите на свою аватарку справа вверху → **Settings**.
2. Слева выберите **Emails**.
3. Поставьте галочку **«Keep my email addresses private»**.
4. Ниже появится адрес вида `12345678+логин@users.noreply.github.com` — **скопируйте его**.
5. Поставьте галочку **«Block command line pushes that expose my email»**.

Теперь **напишите мне (Claude) этот noreply-адрес и ваш логин** — я заменю почту во всех коммитах
и настрою git, чтобы новые коммиты тоже шли с этим адресом. Это нужно сделать **до** шага 1.4.

> Если почта вам не важна — шаги 1.2 можно пропустить, но тогда не ставьте галочку «Block command line pushes…»,
> иначе GitHub не примет проект.

---

## 1.3. Создайте репозиторий

1. Откройте https://github.com/new
2. Заполните:
   - **Repository name:** `hytpotchi`
   - **Description:** `Лаунчер Minecraft` (необязательно)
   - Выберите **Public** — чтобы все могли скачивать. (Если выбрать Private, установщик будет виден только вам.)
3. **Ничего больше не отмечайте**: ни «Add a README», ни «.gitignore», ни «license» —
   всё это уже есть в проекте, иначе будут конфликты.
4. Нажмите зелёную кнопку **Create repository**.
5. Откроется страница с инструкциями. Вверху есть адрес вида
   `https://github.com/ваш-логин/hytpotchi.git` — он понадобится дальше.

---

## 1.4. Отправьте проект на GitHub

1. Откройте терминал в папке проекта (как — написано в [оглавлении](SETUP.md#как-открыть-терминал-в-папке-проекта)).
2. Выполните по очереди три команды. **В первой замените `ваш-логин` на ваш логин GitHub:**

```bash
git remote add origin https://github.com/ваш-логин/hytpotchi.git
```

```bash
git branch -M main
```

```bash
git push -u origin main
```

3. При первой отправке откроется окно **«Connect to GitHub»** (или страница в браузере).
   Нажмите **«Sign in with your browser»** → в браузере **Authorize** → вернитесь в терминал.
4. Когда в терминале появится что-то вроде `branch 'main' set up to track 'origin/main'` — готово.
5. Обновите страницу репозитория на GitHub — там появятся папки `src`, `src-tauri`, `docs` и т.д.

> Сразу после отправки GitHub сам запустит проверку проекта (вкладка **Actions** → «CI»).
> Через ~10 минут там должна появиться зелёная галочка ✅.

---

## 1.5. Добавьте ключ подписи обновлений

Ключ — это файл на вашем компьютере: `C:\Users\akiom31\.tauri\hytpotchi.key`.
GitHub будет подписывать им каждую новую версию.

**Скопируйте ключ:**

1. В терминале выполните (откроется Блокнот с ключом):

```bash
notepad "$env:USERPROFILE\.tauri\hytpotchi.key"
```

2. В Блокноте нажмите **Ctrl+A** (выделить всё), затем **Ctrl+C** (скопировать). Закройте Блокнот, **ничего не меняя**.

**Вставьте его в GitHub:**

3. Откройте ваш репозиторий на GitHub → вкладка **Settings** (шестерёнка вверху, справа от «Insights»).
4. Слева: **Secrets and variables** → **Actions**.
5. Вкладка **Secrets** → зелёная кнопка **New repository secret**.
6. **Name:** `TAURI_SIGNING_PRIVATE_KEY` (именно так, большими буквами, с подчёркиваниями).
7. **Secret:** вставьте ключ (**Ctrl+V**).
8. Нажмите **Add secret**.

Пароль к ключу не нужен — он создан без пароля.

> 🔒 **Сохраните копию ключа в надёжное место** (флешка, личное облако).
> Если ключ потеряется, уже установленные у людей лаунчеры **не смогут обновиться** —
> им придётся скачать установщик заново вручную. Никому не отправляйте этот файл.

---

## 1.6. Выпустите первую версию

1. В терминале выполните две команды:

```bash
git tag v0.2.0
```

```bash
git push origin v0.2.0
```

2. На GitHub откройте вкладку **Actions**. Там появится задача **«Release»** с жёлтым кружком — идёт сборка.
   Это займёт **15–25 минут** (в первый раз дольше). Компьютер можно выключить — собирает GitHub.
3. Когда кружок станет зелёной галочкой ✅ — откройте вкладку **Code** → справа блок **Releases** →
   **Hytpotchi v0.2.0**.
4. Там будет файл **`Hytpotchi_0.2.0_x64-setup.exe`** — это и есть установщик для всех.

**Ссылка, которую можно давать людям:**

```
https://github.com/ваш-логин/hytpotchi/releases/latest
```

Она всегда ведёт на самую новую версию.

> Если вместо галочки красный крестик ❌ — откройте [06-problems.md](06-problems.md#сборка-на-github-упала-красный-крестик).

---

## 1.7. Проверьте автообновление

1. Скачайте `Hytpotchi_0.2.0_x64-setup.exe` со страницы релиза и установите.
2. Откройте лаунчер → **Настройки** → внизу **О программе**. Там должна гореть зелёная точка у **«Обновления»**.
3. Когда вы выпустите `v0.2.1` (см. [05-new-version.md](05-new-version.md)), при следующем запуске лаунчер покажет
   **«Доступна новая версия Hytpotchi 0.2.1 → Обновить»**.

---

✅ **Готово!** Теперь у вас есть ссылка на скачивание и автообновления.
